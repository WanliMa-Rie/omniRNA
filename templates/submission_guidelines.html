Submission Guidelines

During the Competition

Participants submit a single CSV prediction file in the public development phase. Please follow the required task formats exactly and complete the submission metadata fields.

Allowed Resources
  • Public pretrained models are allowed.
  • Public unlabeled RNA sequence resources are allowed.
  • All external resources must be disclosed.
Not Allowed
  • External labeled data that overlap with the released benchmark.
  • Any information derived from hidden test sets.
  • Any information derived from RNA tertiary structures released after the test freeze date.
Submission File Format

Public development submissions must be a single .csv file. Final hidden-phase submissions must be a single .zip file.

The public development CSV must use the following columns: 

task,id,prediction,secondary_pairs,tertiary_coords
fitness,fit_example,0.42,,
structure,str_example,,"[[0, 9], [1, 8]]","[[0.0, 0.0, 0.0], [1.2, 0.1, -0.3]]"
evolution_quartet,quartet_example,2,,
evolution_covariation,cov_example,1,,

The final hidden-phase ZIP must contain exactly four CSV files:

  • fitness.csv with columns id,prediction
  • structure.csv with columns id,secondary_pairs,tertiary_coords
  • evolution_quartet.csv with columns id,prediction
  • evolution_covariation.csv with columns id,prediction
Task-Specific Inputs
  • RNA Fitness Prediction: one numeric prediction per variant id.
  • RNA Structure Prediction: one list of secondary-structure base pairs and one list of 3D nucleotide coordinates per RNA id.
  • RNA Evolutionary Reasoning: one topology label in {0, 1, 2} per quartet id, and one binary label in {0, 1} per covariation id.
