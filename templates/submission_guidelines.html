Submission Guidelines

During the Competition

Participants submit predictions to the public development leaderboard. Please follow the required submission format for the active phase and complete the submission metadata fields.

Allowed Resources

  • Public pretrained models are allowed.
  • Public unlabeled RNA sequence resources are allowed.
  • All external resources must be disclosed.

Not Allowed

  • External labeled data that overlap with the released benchmark.
  • Any information derived from hidden test sets.
  • Any information derived from RNA tertiary structures released after the test freeze date.

Final Submission Requirements

Final evaluation requires an executable Docker submission. Every final submission must include runnable Docker inference code, model weights, a short method sheet, and a statement listing all external data, pretrained models, and compute resources used.

The method sheet must describe the model architecture, training recipe, inference procedure, and resource requirements, and must state whether the submission uses a foundation model, task-specific training, retrieval, or a hybrid method.
